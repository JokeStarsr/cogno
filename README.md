# Cogno Reader

认知增强阅读伴侣 —— 不给你答案，而是推动你思考。

基于浏览器摄像头眼动追踪推断认知状态，在困惑时触发苏格拉底式多代理对话（澄清者 / 挑战者 / 连接者 / 拓展者），配合知识图谱理解网格与间隔回顾，帮助实现真正的深度理解。

基于《未来超级应用白皮书》的 OPC 单人可行方案（阶段一：纯软件）实现。

## 功能

- **阅读面板**：上传 PDF / 粘贴网页 / 粘贴文本 / 内置示例
- **眼动追踪**：WebGazer.js 本地运行，检测注视点、回读、停留时长（相机不可用时自动降级为鼠标代理）
- **认知状态环**：左侧常驻四层圆环 —— 理解深度 / 注意力 / 疲劳 / 心流，呼吸式动画
- **苏格拉底四代理**：不同 System Prompt 的思维角色，检测到困惑/浅层扫描/新概念/深度沉浸时自动介入
- **理解网格**：Cytoscape.js 2D 知识图谱（数据结构与算法垂直领域），节点颜色反映掌握度
- **知识缺口导航**：定位缺失的前置概念，生成修复路径与阻塞度排序
- **间隔回顾**：艾宾浩斯遗忘曲线，卡片式自评复习
- **学习日志**：每日阅读时长、掌握概念数、待复习数（IndexedDB 本地存储）

## 技术栈

React 18 + TypeScript + Vite · WebGazer.js · Cytoscape.js · pdfjs-dist · Dexie (IndexedDB)

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:5173

### 配置 AI 代理

四代理通过 **Anthropic 兼容端点** 调用（兼容 sub2api / DeepSeek anthropic 端点）：

1. 进入「设置」页
2. 填 Base URL：`http://localhost:8180`（本机 sub2api），或任意兼容端点
3. 填 API Key 与模型名
4. Key 仅保存在本机浏览器 localStorage，不上传

### 启用眼动追踪

阅读器右上角「启用眼动」→ 授权摄像头 → 依次点击屏幕上的 8 个校准光点。数据全部本地处理。

## 隐私

眼动数据、阅读记录、认知日志全部存储在浏览器本地（IndexedDB），不上传任何云端。仅向 AI 端点发送你阅读的上下文片段。

## 构建与部署

```bash
npm run build   # 产物在 dist/
```

静态部署到 Vercel / Netlify / Nginx 即可。
